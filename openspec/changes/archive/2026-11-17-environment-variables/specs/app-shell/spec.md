# Spec Delta

## MODIFIED Requirements

### Requirement: Окно и раскладка в стиле Postman
Приложение SHALL открывать главное окно с раскладкой из трёх зон: тулбар сверху, сайдбар проектов слева, основная область (редактор запроса + область ответа) справа.

#### Scenario: Первый запуск на пустом хранилище
- **WHEN** пользователь запускает приложение, а папка хранилища пуста
- **THEN** окно открывается с полной раскладкой, сайдбар показывает пустое состояние с приглашением создать проект

#### Scenario: Состав тулбара
- **WHEN** пользователь смотрит на тулбар
- **THEN** в нём видны название приложения, рабочий селектор окружения (окружения активного проекта и «No Environment») с кнопкой управления окружениями, кнопка переключения темы
