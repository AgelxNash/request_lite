# Spec Delta: request-storage

## MODIFIED Requirements

### Requirement: Перемещение запросов
Пользователь SHALL иметь возможность менять порядок запросов проекта перетаскиванием строк в сайдбаре; итоговый порядок соответствует позиции отпускания кнопки. Начало перетаскивания SHALL отличаться от клика порогом перемещения: короткое нажатие остаётся открытием запроса. Перемещение SHALL сохраняться в файле проекта по завершении перетаскивания и переживать перезапуск. Блокировка проекта не SHALL ограничивать перемещение запросов. Граница зоны закреплённых запросов SHALL быть жёсткой: закреплённый запрос не перетаскивается ниже границы, обычный не входит в зону закреплённых; внутри зоны закреплённых порядок меняется перетаскиванием.

#### Scenario: Перестановка запроса
- **WHEN** пользователь перетаскивает незаблокированный запрос на позицию другого запроса и отпускает кнопку
- **THEN** запрос занимает новую позицию, порядок сохранён на диске и переживает перезапуск

#### Scenario: Клик не является перетаскиванием
- **WHEN** пользователь нажимает кнопку мыши на строке запроса и отпускает её без заметного перемещения
- **THEN** запрос открывается во вкладке, порядок не меняется

#### Scenario: Перемещение при переключении проектов
- **WHEN** пользователь переместил запросы в активном проекте и переключился на другой
- **THEN** перемещения применяются к тому проекту, где они выполнены, другой проект не затронут

#### Scenario: Заблокированный проект не мешает перемещению
- **WHEN** проект заблокирован, и пользователь перетаскивает его незаблокированный запрос
- **THEN** запрос перемещается как обычно

#### Scenario: Граница зон жёсткая
- **WHEN** пользователь перетаскивает закреплённый запрос вниз к обычным, либо обычный запрос вверх к закреплённым, и отпускает кнопку
- **THEN** закрепление запросов не меняется, запросы остаются по свою сторону границы

#### Scenario: Перестановка среди закреплённых
- **WHEN** пользователь перетаскивает закреплённый запрос на позицию другого закреплённого
- **THEN** порядок закреплённых запросов меняется, оба остаются закреплёнными

## ADDED Requirements

### Requirement: Закрепление запросов
Пользователь SHALL иметь возможность закрепить запрос кнопкой в строке сайдбара без подтверждения. Закреплённый запрос SHALL располагаться в верхней зоне списка до всех обычных и отображаться с бейджем закрепления; новый закреплённый встаёт последним среди закреплённых. Закрепление SHALL сохраняться в файле проекта и не сбрасываться при сохранении из вкладки; новые и импортированные запросы создаются незакреплёнными. Закрепление независимо от блокировки и не входит в снимок запроса из вкладки.

#### Scenario: Закрепление кнопкой
- **WHEN** пользователь нажимает кнопку закрепления в строке обычного запроса
- **THEN** запрос перемещается в нижнюю часть верхней зоны, получает бейдж закрепления, порядок сохранён на диске

#### Scenario: Открепление кнопкой
- **WHEN** пользователь нажимает кнопку закрепления в строке закреплённого запроса
- **THEN** запрос открепляется и занимает место среди обычных запросов

#### Scenario: Закрепление переживает перезапуск и сохранение
- **WHEN** пользователь закрепил запрос, перезапустил приложение и затем сохранил этот запрос из вкладки
- **THEN** закрепление сохранилось, сохранение содержимого не сбросило его

#### Scenario: Закрепление и блокировка независимы
- **WHEN** пользователь закрепляет заблокированный запрос
- **THEN** запрос закреплён и остаётся заблокированным: оба индикатора видны, сохранение содержимого по-прежнему отклоняется

#### Scenario: Импорт и новые запросы не закреплены
- **WHEN** пользователь импортирует коллекцию Postman или сохраняет новый запрос
- **THEN** созданные запросы располагаются среди обычных без бейджа закрепления
