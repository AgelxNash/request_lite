# Design

## Context

Снимок вкладки (`toSnapshot`) — единственная форма запроса, через которую уже идут сохранение и отправка. Импорт и экспорт оперируют тем же снимком: парсер строит его из токенов curl, генератор восстанавливает из него. KV-поля и auth уже нормализованы. Контекстное меню вкладки (`RequestTabs.vue` + `ContextMenu.vue`) готово к расширению пунктом.

## Goals / Non-Goals

**Goals:**
- Круг «вставил команду → вкладка → экспорт → та же команда» с round-trip без потерь.

**Non-Goals:**
- Файлы в multipart (`-F name=@path` → литерал), не-http схемы, прочие флаги curl (`--compressed`, `-k`, `-L` и т.п. — игнорируются), пакетный импорт, сохранение истории импортов, отдельное окно экспорта.

## Decisions

### D1. `lib/curl.js` — чистый модуль, один файл
`parseCurl(text)` и `generateCurl(snapshot)` без зависимостей (паттерн `variables.js`): smoke-тесты гоняют их в Node, включая round-trip. Токенизатор отдельной функцией `tokenizeShell(text)`: пробельные разделители, `'…'` — литерал (конкатенация смежных токенов не нужна — curl-команды обычно разделяются пробелом), `"…"` — с обработкой `\"` `\\` `\n` `$` не раскрывается, `\x` вне кавычек — литеральный `x`, `\` перед переводом строки — перенос. Ведущий токен `curl` (и полный путь `/usr/bin/curl`) отбрасывается.

### D2. Разбор флагов
Итерация по токенам: длинные флаги `--name value` / `--name=value`, короткие `-X value` / `-Xvalue` (слитная форма для однобуквенных). Неизвестные флаги и их значения пропускаются (длина значения определяется по известному набору требующих значения флагов curl — консервативно: неизвестный флаг без значения пропускается как токен). Первый http/https-токен вне флага — URL. При `-d*` без `-X` метод POST (AGENTS.md); `-G` меняет семантику: метод GET, части `-d` до первого `&` (или целиком) раскладываются в `searchParams.append` как пары `k=v`. `--json` → `body.type='json'` + заголовок Content-Type (если не задан). `-d` → `body.type='text'`; если в данных есть `=` и `&` и нет Content-Type — оставляем text (не угадываем urlencoded: round-trip предсказуемее). Несколько `-d` склеиваются `\n`? curl склеивает без разделителя; для предсказуемости — конкатенация без разделителя, как curl. `-b` → header Cookie (без разбора на куки). `-u` → split по первому `:` → basic (без `:` — пароль пустой).

### D3. Генерация
Порядок: `curl 'URL'` → метод (`-X`, если не GET) → auth (`-u` для basic; bearer/apikey — заголовками) → заголовки `-H 'k: v'` (включая Content-Type для json/text — если он не перекрыт пользовательским, добавляется как авто-заголовок) → тело: json/text `-d '…'`, urlencoded — по паре `--data-urlencode 'k=v'` (curl закодирует сам; в снимке значения сырые), form-data → `-F 'k=v'`. GET с телом не генерирует тело (GET/HEAD без тела — поведение sendRequest). Экранирование значений: обёртка в `'…'`, `'` → `'\''`. `{{var}}` не трогается.

### D4. Куда лочится UI
Импорт: `CurlImportDialog.vue` (own overlay, textarea моноширинная, кнопка «Импорт», ошибка красным) — открывается из `App.vue` по `menu:import-curl` ( accelerator `CmdOrCtrl+I`). Успех: `tabs.openTabFromSnapshot(snapshot)` (новый action — как `openSaved`, но без связи), имя — `suggestRequestName(url)` или «Imported Request».

Экспорт: `RequestTabs.vue` контекстное меню → пункт «Копировать как cURL» (для любой вкладки) → `curl` строка из `generateCurl(toSnapshot(tab))` → панель. `CurlExportPanel.vue` — фиксированная шторка справа (правая половина editor-area, overlay поверх ответа), код-блок (`white-space: pre`, selectable), кнопки «Копировать» и закрытия, Esc закрывает. Копирование через `clipboard:write` IPC → `clipboard.writeText` (electron) в main — надёжнее renderer-clipboard (не требует permission handler). Тот же пункт не добавляется в «Файл»: контекстное меню покрывает сценарий (любая вкладка через ПКМ).

### D5. Round-trip как контракт
Smoke-тест: `parseCurl(generateCurl(snapshot))` воспроизводит method/url/headers/body/auth для комбинированного снимка (params + headers + bearer + json + urlencoded + basic). Не round-trip-тривиальные поля (params в URL при экспорте — они часть URL; при импорте URL с query → params остаются в URL, отдельной таблицей не выделяются) фиксируются в тестах как допустимое поведение: round-trip сохраняет эффективный запрос, а не пофамильную структуру таблиц. В спеке требование сформулировано по эффективным полям.

## Risks / Trade-offs

- [curl-команды с экзотикой ($', ANSI-C кавычки, переменные shell `$VAR`)] → токенизатор обрабатывает стандартные кавычки; `$VAR` остаётся литералом (пользователь видит неразрешённое) — документировано.
- [Неизвестный флаг с «пожиранием» URL] → URL ищется среди токенов вне флагов по схеме http/https; если флаг съел URL — понятная ошибка «URL не найден».
- [Панель поверх ответа] → шторка с тенью, закрытие по Esc/кнопке; после закрытия ответ на месте.
- [`-d` склейка без разделителя] → соответствует поведению curl; редкий сценарий.
