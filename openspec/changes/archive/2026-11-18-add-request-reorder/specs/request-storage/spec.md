# Spec Delta: request-storage

## MODIFIED Requirements

### Requirement: Список запросов проекта в сайдбаре
Сайдбар SHALL показывать запросы активного проекта (метод и имя) в порядке, заданном пользователем перемещением (по умолчанию — порядок добавления). При переключении активного проекта список SHALL меняться на запросы выбранного проекта, порядок сохраняется в файле проекта.

#### Scenario: Переключение проектов
- **WHEN** пользователь кликает по другому проекту в сайдбаре
- **THEN** список запросов меняется на запросы выбранного проекта

#### Scenario: Порядок сохраняется при переключении
- **WHEN** пользователь переместил запросы в проекте, переключился на другой проект и вернулся
- **THEN** список первого проекта отображается в оставленном пользователем порядке

## ADDED Requirements

### Requirement: Перемещение запросов
Пользователь SHALL иметь возможность менять порядок запросов проекта перетаскиванием строк в сайдбаре; итоговый порядок соответствует позиции отпускания кнопки. Начало перетаскивания SHALL отличаться от клика порогом перемещения: короткое нажатие остаётся открытием запроса. Перемещение SHALL сохраняться в файле проекта по завершении перетаскивания и переживать перезапуск. Блокировка проекта не SHALL ограничивать перемещение запросов.

#### Scenario: Перестановка запроса
- **WHEN** пользователь перетаскивает незаблокированный запрос на позицию другого запроса и отпускает кнопку
- **THEN** запрос занимает новую позицию, порядок сохранён на диске и переживает перезапуск

#### Scenario: Клик не является перетаскиванием
- **WHEN** пользователь нажимает кнопку мыши на строке запроса и отпускает её без заметного перемещения
- **THEN** запрос открывается во вкладке, порядок не меняется

#### Scenario: Перемещение при переключении проектов
- **WHEN** пользователь переместил запросы в активном проекте и переключился на другой
- **THEN** перемещения применяются к тому проекту, где они выполнены, другой проект не затронут

#### Scenario: Заблокированный проект не мешает перемещению
- **WHEN** проект заблокирован, и пользователь перетаскивает его незаблокированный запрос
- **THEN** запрос перемещается как обычно

### Requirement: Перемещение и блокировка запросов
Заблокированный запрос SHALL быть защищён от перетаскивания: перетаскивание на его строке не начинается. Другие запросы при этом SHALL перемещаться мимо него: позиция заблокированного в списке может меняться без изменения его содержимого.

#### Scenario: Заблокированный запрос не перетаскивается
- **WHEN** пользователь пытается перетащить строку заблокированного запроса
- **THEN** перетаскивание не начинается, порядок не меняется

#### Scenario: Незаблокированный перемещается мимо заблокированного
- **WHEN** пользователь перетаскивает незаблокированный запрос через позицию заблокированного и отпускает кнопку
- **THEN** запрос занимает новую позицию, заблокированный сдвигается в списке, его содержимое остаётся неизменным
