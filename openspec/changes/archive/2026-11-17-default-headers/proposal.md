# Proposal

## Why

Отправляемые запросы не несут стандартных заголовков клиента: User-Agent уходит как `node`, Accept — как `*/*`. Реальные API часто ведут себя по-разному в зависимости от этих заголовков, и пользователь вынужден заполнять их вручную перед каждым запросом.

## What Changes

- Новая вкладка запроса создаётся с предзаполненной таблицей Headers — включённые стандартные заголовки: `User-Agent: PostmanLite/1.0`, `Accept: application/json`, `Accept-Language: ru-RU,ru;q=0.9`.
- Дефолты — обычные строки таблицы: можно редактировать, снять галочку (не отправляется) или удалить; после удаления заново не восстанавливаются.
- Включённый заголовок заменяет автозначение undici (дублирования нет — проверено эмпирически); снятая галочка возвращает автозначение клиента.
- Счётчик активных заголовков рядом с вкладкой Headers — как уже сделано у Params.
- Набор дефолтов вынесен в чистый модуль `lib/defaults.js` и покрыт smoke-тестами.

Вне scope: настройка набора дефолтов в настройках приложения; `Content-Type` дефолтом (он ставится автоматически по типу Body); предзаполнение Params; восстановление удалённых дефолтов.

### New Capabilities

(нет)

### Modified Capabilities

- `request-execution`: MODIFIED требования «Редактирование заголовков запроса» — добавляются предзаполнение стандартных заголовков в новой вкладке и счётчик активных заголовков; существующие сценарии сохраняются.

## Impact

- `src/renderer/src/lib/defaults.js` — новый чистый модуль с набором дефолтов.
- `src/renderer/src/stores/tabs.js` — `makeTab` использует дефолты.
- `src/renderer/src/components/RequestEditor.vue` — бейдж счётчика на вкладке Headers.
- `scripts/smoke.mjs` — тесты дефолтов и их отправки.
- Зависимости не добавляются.
