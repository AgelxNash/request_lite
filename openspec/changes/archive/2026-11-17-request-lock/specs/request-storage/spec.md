# Spec Delta

## ADDED Requirements

### Requirement: Блокировка запроса
Сайдбар SHALL позволять заблокировать и разблокировать сохранённый запрос кнопкой-замком в строке запроса; переключение SHALL выполняться через окно подтверждения. Заблокированный запрос SHALL иметь индикатор-замок у имени в сайдбаре. Состояние блокировки SHALL сохраняться между запусками. Блокировка ограничивает только сохранение изменений и удаление: отправка, редактирование вкладок-черновиков, клонирование и импорт не ограничиваются.

#### Scenario: Блокировка с подтверждением
- **WHEN** пользователь нажимает кнопку-замок у разблокированного запроса и подтверждает диалог
- **THEN** запрос заблокирован: у имени в сайдбаре отображается индикатор-замок, состояние сохраняется на диске

#### Scenario: Разблокировка с подтверждением
- **WHEN** пользователь нажимает кнопку-замок у заблокированного запроса и подтверждает диалог
- **THEN** блокировка снимается, индикатор исчезает

#### Scenario: Отмена подтверждения
- **WHEN** пользователь отклоняет диалог подтверждения при переключении блокировки
- **THEN** состояние запроса не меняется

#### Scenario: Блокировка переживает перезапуск
- **WHEN** пользователь блокирует запрос и перезапускает приложение
- **THEN** запрос остаётся заблокированным с индикатором

#### Scenario: Блокировка не ограничивает отправку и клонирование
- **WHEN** запрос заблокирован, и пользователь открывает его в вкладке, отправляет и клонирует
- **THEN** отправка и клонирование выполняются как обычно; клон сохраняется как новый запрос

### Requirement: Удаление заблокированного запроса
Заблокированный запрос SHALL быть защищён от удаления: кнопка удаления в сайдбаре неактивна с подсказкой, а хранилище SHALL отклонять запрос на удаление заблокированного запроса. После разблокировки удаление работает как прежде (с подтверждением).

#### Scenario: Кнопка удаления неактивна
- **WHEN** запрос заблокирован, и пользователь наводит курсор на кнопку удаления в сайдбаре
- **THEN** кнопка неактивна с подсказкой «Запрос заблокирован»

#### Scenario: Хранилище отклоняет удаление
- **WHEN** запрос на удаление заблокированного запроса достигает хранилища (минуя UI)
- **THEN** удаление отклоняется с ошибкой, запись остаётся на месте

#### Scenario: Удаление после разблокировки
- **WHEN** пользователь разблокирует запрос и запрашивает удаление с подтверждением
- **THEN** запрос удаляется как обычно

## MODIFIED Requirements

### Requirement: Сохранение запроса в активный проект
Кнопка Save в строке запроса и пункт меню Save Request (`CmdOrCtrl+S`) SHALL сохранять снимок запроса из активной вкладки в активный проект. При первом сохранении несвязанной вкладки SHALL запрашиваться имя запроса (диалог с предзаполнением из URL); повторное сохранение связанной вкладки обновляет тот же запрос без диалога. Если активного проекта нет, Save SHALL быть недоступен. Обновление заблокированного запроса SHALL отклоняться: Save связанной с заблокированным запросом вкладки неактивен с подсказкой, а хранилище отклоняет upsert существующего заблокированного запроса; создание нового запроса не ограничивается.

#### Scenario: Первое сохранение с диалогом имени
- **WHEN** пользователь нажимает Save на несвязанной вкладке с URL `https://example.com/api`
- **THEN** открывается диалог с именем, предзаполненным из URL, и после подтверждения запрос появляется в сайдбаре активного проекта, вкладка связывается с ним

#### Scenario: Повторное сохранение без диалога
- **WHEN** пользователь меняет URL связанной вкладки и снова нажимает Save
- **THEN** сохранённый запрос в проекте обновляется без диалога имени

#### Scenario: Нет активного проекта
- **WHEN** в приложении нет ни одного проекта
- **THEN** кнопка Save неактивна

#### Scenario: Save неактивен для связанной вкладки заблокированного запроса
- **WHEN** вкладка связана с заблокированным запросом, и пользователь наводит курсор на кнопку Save
- **THEN** кнопка Save и пункт меню «Сохранить» неактивны с подсказкой «Запрос заблокирован — разблокируйте, чтобы сохранить»

#### Scenario: Хранилище отклоняет обновление заблокированного
- **WHEN** запрос на обновление существующего заблокированного запроса достигает хранилища (минуя UI)
- **THEN** сохранение отклоняется с ошибкой, запись остаётся неизменной

#### Scenario: Создание нового запроса не ограничено
- **WHEN** пользователь сохраняет несвязанную вкладку или клон под новым именем
- **THEN** новый запрос создаётся как обычно
