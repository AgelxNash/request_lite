# Proposal

## Why

Порядок проектов в сайдбаре фиксирован порядком создания: рабочий проект нельзя поставить первым. Для запросов внутри проекта перемещение уже реализовано (change `add-request-reorder`) — списки должны вести себя единообразно. Порядок проектов уже хранится как порядок массива в `projects.json` — не хватает операции перестановки и её UI.

## What Changes

- Перетаскивание проектов в списке «Проекты» сайдбара для смены порядка: pointer-drag по образцу перемещения запросов (порог клик-vs-drag, живая перестановка, window-слушатели без pointer capture).
- Заблокированный проект нельзя перетащить как источник (drag на его строке не начинается), но другие проекты перемещаются мимо него: позиция заблокированного в списке меняется, содержимое и защита от удаления не затрагиваются — соответствует спеке блокировки (ограничивает только удаление).
- Новый IPC-канал `projects:reorder` + функция в хранилище: порядок сохраняется в индекс `projects.json` одной атомарной записью по завершении drag и переживает перезапуск.
- Выбор активного проекта не зависит от перемещения: клик выбирает проект, drag меняет только порядок.
- Автоскролл списка проектов у краёв при переполнении (по образцу списка запросов).

Вне скоупа: drag между группами/папками проектов, сортировка по клику, перемещение окружений.

### Modified Capabilities

## Impact

- `src/main/storage.js` — функция `reorderProjects(id, toIndex)` для индекса (паттерн `renameProject`).
- `src/main/ipc.js` + `src/preload/index.js` — канал `projects:reorder`, мост `window.api.projects.reorder`.
- `src/renderer/src/stores/projects.js` — экшены `moveLocal`/`reorder` (по образцу `requests.js`).
- `src/renderer/src/components/ProjectList.vue` — pointer-drag строк.
- `src/renderer/src/assets/style.css` — grab-курсор и стили drag.
- Скрипт smoke — тесты функции переупорядочивания индекса.
