# Design

## Context

Сохранение уже реализовано как `saveActiveViaDialog(dialog)` — работает только с активной вкладкой. Вкладки рендерятся в `RequestTabs.vue` (кнопки в строке). В проекте есть прецедент отказа от нативных диалогов (`AppDialog`) — интерфейс строится веб-компонентами.

## Goals / Non-Goals

**Goals:**
- Меню из двух пунктов на правый клик по любой вкладке; действия таргетят кликнутую вкладку.

**Non-Goals:**
- Нативное системное меню, другие пункты (переименование, «закрыть прочие»), контекстные меню сайдбара, подменю.

## Decisions

### D1. Веб-меню — компонент `ContextMenu.vue`
Фиксированный div, позиционируемый у курсора (`position: fixed; left/top` от `contextmenu`-события), список пунктов с поддержкой `disabled`. Закрытие: клик вне, Esc, выбор пункта. Открывается из `RequestTabs.vue` обработчиком `@contextmenu.prevent` на вкладке — Vue-событие, нативное контекстное меню браузера подавляется. Альтернатива `Menu.popup` через IPC отклонена: системный вид диссонирует с темой, недоступен для CDP-проверок, добавляет канал.

### D2. Таргетинг — `saveTab(id, dialog)` вместо `saveActiveViaDialog`
`saveActiveViaDialog(dialog)` рефакторится в `saveTab(id, dialog)`: тот же алгоритм, но вкладка берётся по id, а не `activeTab`. Старое имя — обёртка `saveTab(activeTabId, ...)` для кнопки Save и меню `CmdOrCtrl+S`. Ключевой эффект: «Сохранить» из меню обновляет запрос кликнутой вкладки, не трогая активную.

### D3. `cloneTab(id)` — снимок без связи
Новая вкладка строится из `toSnapshot(source)`: поля контента копируются (params/headers дополняются пустой строкой, body/auth клонируются глубоко), `name` = `«имя (копия)»`, `savedRequestId = null`, `dirty = false`, runtime сброшен. Клон становится активной. Первый Save клона создаёт новый запрос — существующая логика upsert по `savedRequestId: null` уже это делает.

### D4. Предзаполнение имени у несвязанной вкладки
В диалоге сохранения подсказка: `suggestRequestName(url)`, а если вкладка уже переименована (name ≠ `Untitled Request`) — её текущее имя. Для клона это даёт «имя (копия)» в подсказке, сохраняя пользовательский контекст.

### D5. Состояния пунктов
«Сохранить» — `disabled` при отправке запроса вкладки или отсутствии активного проекта; «Клонировать» — доступен всегда (работает и без проекта). Отсутствие проекта показывается title-подсказкой на пункте.

## Risks / Trade-offs

- [Меню у края окна выходит за границы] → позиционирование с clamp по размерам окна (right/bottom флип).
- [Пункты меню без иконок выглядят проще Postman] → вне scope, итерация по потребности.
- [Двойной контекст (вкладка + URL-бар)] → обработчик вешается только на вкладки строки вкладок.
