# Proposal

## Why

Приложение — локальный клиент HTTP, и его данные (проекты, запросы, окружения) уже лежат в JSON-файлах, а выполнение запросов живёт в main-процессе. Подъём MCP-сервера (Model Context Protocol) позволяет подключать ИИ-агентов (ZCode, Claude Desktop, Cursor и др.) к этим данным и к выполнению запросов: агент сможет смотреть коллекции, отправлять запросы, создавать/править записи и работать с curl — без ручного копирования. Вся предметная логика (`storage.js`, `http.js`, `lib/curl.js`) не зависит от Electron и переиспользуется сервером напрямую.

## What Changes

- Новый модуль `src/main/mcp.js`: MCP-сервер поверх Streamable HTTP (JSON-RPC 2.0 на `node:http`), без внешних зависимостей; запускается из `index.js` после `bootstrap()`.
- Транспорт: только `127.0.0.1`, порт настраивается; ответы — обычным JSON (SSE-поток не нужен, все операции укладываются в один ответ).
- Реестр инструментов для ИИ: просмотр проектов/запросов/окружений, создание/обновление/удаление запроса (с уважением к `locked`), отправка сохранённого и произвольного запроса, импорт/экспорт curl.
- Безопасность: токен в `settings.json` (`Authorization: Bearer`), генерируется при первом включении сервера.
- Настройки: новые поля `mcp: {enabled, port, token}` в `settings.json`; отдельная страница настроек с двумя параметрами MCP — включение (по умолчанию выключено) и порт (по умолчанию 45460); при включённом сервере на странице показывается блок информации о подключении (адрес, токен, фрагмент конфигурации клиента).
- IPC: новые каналы с префиксом `mcp:*` (статус сервера, изменение конфигурации с перезапуском слушателя).

## Capabilities

### New Capabilities

- `mcp-server`: внешний программный интерфейс для ИИ-агентов — MCP-сервер на localhost: транспорт Streamable HTTP, рукопожатие и список/вызов инструментов, правила безопасности (локальный бинд, токен, включение по явной настройке), состав инструментов и их гарантии (блокировка записей, лимиты тела ответа).

## Impact

- **Код:** `src/main/index.js` (запуск/остановка сервера), новый `src/main/mcp.js`; `src/main/ipc.js` — каналы `mcp:*`; `src/main/storage.js` — значения настроек MCP по умолчанию; renderer — новая страница настроек (точка входа в меню приложения) и `src/preload/index.js` (проброс `window.api.mcp.*`).
- **Зависимости:** новых нет — сервер пишется на `node:http` (JSON-RPC 2.0 — это просто диспетчер методов).
- **Данные:** расширение `settings.json` полями `mcp: {enabled, port, token}`; файлы проектов и запросов не меняются.
- **AGENTS.md:** дополнить список IPC-префиксов каналом `mcp:*`.
- **Безопасность:** сервер слушает только loopback и закрыт токеном; ИИ получает возможность реально отправлять сетевые запросы и менять данные — включение остаётся явным действием пользователя.
