# Spec Delta: app-shell

## ADDED Requirements

### Requirement: Переименование вкладок
Пользователь SHALL иметь возможность переименовать вкладку из контекстного меню («Переименовать») и двойным кликом по имени вкладки; двойной клик по остальной части вкладки сохраняет своё действие (закрепление/открепление). Переименование SHALL открывать диалог с текущим именем; пустое имя и отмена не меняют вкладку. Переименование SHALL помечать вкладку индикатором несохранённых изменений и не SHALL затрагивать сохранённый запрос до сохранения вкладки.

#### Scenario: Переименование из контекстного меню
- **WHEN** пользователь выбирает «Переименовать» в контекстном меню вкладки и вводит новое имя
- **THEN** имя вкладки меняется, на ней отображается индикатор несохранённых изменений

#### Scenario: Двойной клик по имени вкладки
- **WHEN** пользователь дважды кликает по имени вкладки
- **THEN** открывается диалог переименования, закрепление/открепление не выполняется

#### Scenario: Двойной клик вне имени
- **WHEN** пользователь дважды кликает по части вкладки вне имени
- **THEN** выполняется закрепление/открепление вкладки, диалог переименования не открывается

#### Scenario: Отмена и пустое имя
- **WHEN** пользователь отменяет диалог переименования или подтверждает пустое имя
- **THEN** имя вкладки не меняется, индикатор не появляется

#### Scenario: Переименование не затрагивает сохранённый запрос
- **WHEN** пользователь переименовывает вкладку, связанную с сохранённым запросом, и не сохраняет её
- **THEN** запрос в сайдбаре остаётся со старым именем; новое имя попадёт в запрос при последующем сохранении вкладки
