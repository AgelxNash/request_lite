# Proposal

## Why

Вкладку нельзя переименовать: её имя появляется только косвенно (при сохранении, клонировании, импорте), и все несохранённые черновики зовутся «Untitled Request» — при нескольких открытых вкладках их невозможно различить. При этом логика подстановки имени переименованной вкладки в диалог сохранения уже реализована в сторе (предпочитает имя вкладки имени из URL) и простаивает — не хватает самого переименования.

## What Changes

- Пункт «Переименовать» в контекстном меню вкладки и двойной клик по имени вкладки (не по всей вкладке — двойной клик по ней остаётся закреплением/откреплением); диалог — тот же prompt, что у переименования проектов и сохранения запроса.
- Переименование меняет `name` вкладки и помечает её индикатором несохранённых изменений (точкой): имя входит в снимок запроса.
- Для связанной вкладки Save после переименования молча обновляет имя сохранённого запроса (существующий upsert); для несвязанной — имя вкладки подставляется в диалог сохранения по умолчанию (уже работающая логика стора).
- Спека `request-storage` дополняется приоритетом подстановки (имя переименованной вкладки важнее URL) и выравнивается с фактическим поведением индикатора: точка показывается на любой изменённой вкладке, не только связанной (код давно так работает — существующий дрейф спеки, который трогает данное изменение).

Вне скоупа: inline-редактирование имени прямо в вкладке, переименование сохранённых запросов из сайдбара (там свои диалоги), горячие клавиши.

### Modified Capabilities

- `app-shell`: добавляется требование «Переименование вкладок» — UI-действие строки вкладок (по образцу того, как туда легли закрепление и перетаскивание).
- `request-storage`: модифицируются «Сохранение запроса в активный проект» (приоритет подстановки имени в диалоге сохранения) и «Индикатор несохранённых изменений» (точка на любой изменённой вкладке, включая переименование; выравнивание с кодом).

## Impact

- `src/renderer/src/stores/tabs.js` — экшен `renameTab(id, name)` (name + dirty).
- `src/renderer/src/components/RequestTabs.vue` — пункт меню, обработчик двойного клика по имени, вызов `dialog.prompt`.
- main-процесс, IPC, хранилище, зависимости — без изменений.
