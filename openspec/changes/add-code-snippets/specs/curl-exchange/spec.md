# Spec Delta: curl-exchange

## ADDED Requirements

### Requirement: Выбор языка в панели экспорта
Панель экспорта SHALL содержать селектор языков: cURL, JavaScript Fetch, JavaScript Axios, Python Requests. При открытии выбирается cURL, а если язык уже выбирался в этом запуске приложения — последний выбранный. Переключение SHALL показывать код того же снимка кликнутой вкладки, для которого панель открыта.

#### Scenario: Открытие панели
- **WHEN** пользователь впервые в этом запуске приложения выбирает «Сгенерировать код» в меню вкладки
- **THEN** панель открывается с выбранным языком cURL и командой curl кликнутой вкладки

#### Scenario: Переключение языка
- **WHEN** пользователь выбирает в селекторе панели «Python Requests»
- **THEN** код-блок показывает сниппет Python для той же вкладки, для которой панель открыта

#### Scenario: Язык запоминается
- **WHEN** пользователь закрыл панель и снова открывает её в этом запуске приложения
- **THEN** панель открывается с ранее выбранным языком

#### Scenario: Снимок зафиксирован при открытии
- **WHEN** после открытия панели пользователь меняет URL вкладки
- **THEN** показанный код и код при переключении языка остаются построенными по снимку на момент открытия

## MODIFIED Requirements

### Requirement: Экспорт запроса в команду curl
Контекстное меню вкладки (правый клик по любой вкладке) SHALL содержать пункт «Сгенерировать код», строящий команду curl из снимка вкладки: не-GET метод → `-X`; заголовки → `-H`; bearer → заголовок `Authorization`, apikey → заголовок или query, basic → `-u`; тело json/text → `-d` с `Content-Type`, urlencoded → `--data-urlencode` на пару, form-data → `-F`; значения — в одинарных кавычках с экранированием `'` → `'\''`; переменные `{{var}}` — литерально.

#### Scenario: Экспорт запроса с auth и телом
- **WHEN** пользователь открывает меню вкладки с методом POST, URL `https://api.example.com`, bearer-токеном `t-1` и json-телом и выбирает «Сгенерировать код»
- **THEN** панель показывает команду curl с `-X POST`, `-H 'Authorization: Bearer t-1'` и `-d '{"…"}'` с `-H 'Content-Type: application/json'`

#### Scenario: Экспорт basic-авторизации
- **WHEN** пользователь экспортирует вкладку с auth basic (логин `user`, пароль `p@ss`)
- **THEN** команда содержит `-u 'user:p@ss'`

#### Scenario: Экранирование кавычек
- **WHEN** экспортируемое значение содержит одинарную кавычку
- **THEN** в команде кавычка экранирована как `'\''`, и команда корректно выполняется в shell

#### Scenario: Переменные литерально
- **WHEN** пользователь экспортирует вкладку с URL `{{baseUrl}}/echo`
- **THEN** команда содержит литеральный `{{baseUrl}}`, а не значение активного окружения

### Requirement: Панель экспорта с копированием
Пункт «Сгенерировать код» SHALL открывать панель-шторку справа с кодом выбранного языка в код-блоке: текст доступен для выделения; кнопка «Копировать» SHALL помещать показанный код в системный буфер обмена; панель закрывается по кнопке и по Esc.

#### Scenario: Копирование в буфер
- **WHEN** пользователь нажимает «Копировать» в панели экспорта
- **THEN** показанный код помещается в системный буфер обмена

#### Scenario: Закрытие панели
- **WHEN** пользователь закрывает панель кнопкой или Esc
- **THEN** панель исчезает, содержимое вкладки и ответ не затронуты
