# Proposal

## Why

Сохранённые запросы — актив, который легко потерять: случайный ✕ в сайдбаре или повторный Save по связанной вкладке молча перезаписывают содержимое. Блокировка запроса даёт защиту на уровне записи: заблокированный запрос нельзя удалить и нельзя изменить (обновить сохранение), при этом вкладка остаётся редактируемой как черновик, отправка не ограничена, а для правок есть клон.

## What Changes

- Модель: `locked: boolean` в записи запроса в `requests[]` файла проекта (отсутствует = `false`).
- Хранилище: `setRequestLocked(projectId, requestId, locked)`; guard'ы — `saveRequest` отклоняет upsert **существующего** заблокированного запроса (создание нового не ограничено), `deleteRequest` отклоняет удаление заблокированного.
- IPC: `requests:setLocked {projectId, requestId, locked}` → обновлённый список.
- UI сайдбара: кнопка-замок 🔓/🔒 третьей в actions строки запроса (переключение через окно подтверждения в обе стороны), 🔒-индикатор у имени заблокированного запроса, ✕ неактивна с подсказкой «Запрос заблокирован».
- UI вкладок: кнопка Save и пункт контекстного меню «Сохранить» неактивны, когда вкладка связана с заблокированным запросом (tooltip «Запрос заблокирован — разблокируйте, чтобы сохранить»); dirty-точка и редактирование работают как обычно (вкладка — черновик).
- Отправка, клонирование (несвязанная копия) и импорт curl не ограничиваются; клон сохраняется как новый запрос свободно.
- Удаление проекта удаляет и заблокированные запросы внутри него — проектный confirm покрывает операцию целиком.

Вне scope: пароль на разблокировку; read-only вкладок; блокировка по умолчанию; блокировка отдельных секций запроса.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `request-storage`: ADDED требования «Блокировка запроса» (переключение с подтверждением, индикаторы, персистентность, что не ограничено) и «Удаление заблокированного запроса»; MODIFIED «Сохранение запроса в активный проект» (обновление заблокированного отклоняется, создание нового не ограничено).

## Impact

- `src/main/storage.js` — `setRequestLocked`, guard'ы в `saveRequest`/`deleteRequest`.
- `src/main/ipc.js`, `src/preload/index.js` — канал `requests:setLocked`, `api.requests.setLocked`.
- `src/renderer/src/components/RequestList.vue` — кнопка-замок, индикатор, неактивная ✕.
- `src/renderer/src/components/RequestTabs.vue`, `RequestEditor.vue` — неактивный Save при связи с заблокированным запросом.
- `src/renderer/src/stores/requests.js` — action `setLocked`.
- `scripts/smoke.mjs` — тесты guard'ов.
- Зависимости не добавляются.
