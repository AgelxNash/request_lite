# Spec Delta: request-execution

## MODIFIED Requirements

### Requirement: Отображение ответа
Область ответа SHALL показывать строку статуса (код, время, размер), заголовки ответа и тело ответа. JSON-тело SHALL отображаться отформатированным с подсветкой синтаксиса; не-JSON — как обычный текст. До первой отправки SHALL показываться пустое состояние, кроме случая, когда открыт сохранённый запрос с историей: тогда SHALL показываться последний сохранённый ответ с пометкой «из истории» и временем получения (поведение определяет capability `response-history`).

#### Scenario: JSON-ответ с подсветкой
- **WHEN** сервер возвращает тело с `Content-Type: application/json`
- **THEN** тело отображается отформатированным с подсветкой синтаксиса

#### Scenario: Не-JSON ответ
- **WHEN** сервер возвращает тело `text/plain`
- **THEN** тело отображается как обычный текст без форматирования

#### Scenario: Заголовки ответа доступны
- **WHEN** ответ получен, и пользователь открывает раздел заголовков ответа
- **THEN** отображаются пары «ключ — значение» заголовков ответа

#### Scenario: Несохранённый запрос до первой отправки
- **WHEN** пользователь открывает вкладку несохранённого запроса или сохранённый запрос без истории
- **THEN** область ответа показывает пустое состояние

#### Scenario: Переоткрытый сохранённый запрос с историей
- **WHEN** пользователь открывает сохранённый запрос, у которого есть сохранённые ответы, до новой отправки
- **THEN** область ответа показывает последний сохранённый ответ с пометкой «из истории» и временем получения
