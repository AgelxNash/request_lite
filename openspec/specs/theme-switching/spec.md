# theme-switching Specification

## Purpose

Переключение тёмной и светлой темы интерфейса с сохранением выбора пользователя между запусками. Capability фиксирует поведение цветов интерфейса как внешне наблюдаемое свойство приложения.

## Requirements

### Requirement: Тема по умолчанию
При отсутствии сохранённого выбора приложение SHALL использовать тёмную тему.

#### Scenario: Первый запуск
- **WHEN** пользователь запускает приложение, а файл настроек ещё не существует
- **THEN** интерфейс отображается в тёмной теме

### Requirement: Переключение темы из интерфейса
Приложение SHALL переключать тёмную и светлую тему по кнопке в тулбаре немедленно, без перезапуска приложения.

#### Scenario: Переключение на светлую
- **WHEN** пользователь нажимает кнопку переключения темы в тулбаре
- **THEN** все зоны интерфейса перекрашиваются в светлую палитру без перезапуска и без смещения раскладки

#### Scenario: Обратное переключение
- **WHEN** пользователь снова нажимает кнопку переключения темы
- **THEN** интерфейс возвращается к тёмной палитре

### Requirement: Сохранение выбора темы
Приложение SHALL сохранять выбор темы пользователя и восстанавливать его при следующем запуске.

#### Scenario: Тема переживает перезапуск
- **WHEN** пользователь выбрал светлую тему и перезапустил приложение
- **THEN** интерфейс открывается в светлой теме

#### Scenario: Хранилище выбора
- **WHEN** пользователь переключает тему
- **THEN** выбор записывается в файл настроек в папке хранилища приложения
