# postman-import Specification

## Purpose

Импорт коллекции Postman v2.x из JSON-файла в новый проект: дерево запросов с папками-префиксами, конвертация полей (URL/params, headers, auth, тела), переменные коллекции в окружение с именем коллекции. Разбор ошибок не оставляет мусора в хранилище.

## Requirements

### Requirement: Импорт файла коллекции в новый проект
Пункт меню «Импорт коллекции Postman» SHALL открывать выбор JSON-файла и создавать новый проект с именем `info.name` коллекции: запросы коллекции сохраняются в него в порядке обхода, окружение с именем коллекции содержит переменные `collection.variable`, и это окружение становится активным. Проект после импорта SHALL стать активным и появиться в сайдбаре. Неразборчивый файл (не JSON, не коллекция v2.x — нет `info.name` или `item`) SHALL давать понятное сообщение об ошибке без создания проекта.

#### Scenario: Импорт типичной коллекции
- **WHEN** пользователь импортирует коллекцию с `info.name: «API Demo»`, двумя запросами и переменной `baseUrl`
- **THEN** появляется проект «API Demo» (активный), в сайдбаре два запроса в порядке обхода, в селекторе окружение «API Demo» (активное) с переменной `baseUrl`

#### Scenario: Ошибка разбора
- **WHEN** пользователь выбирает файл, который не является JSON или коллекцией v2.x
- **THEN** показывается понятное сообщение об ошибке, проект и окружение не создаются

### Requirement: Дерево запросов и папки-префиксы
Папки коллекции (включая вложенные) SHALL разворачиваться в плоский список запросов с именем «Папка / Запрос» (вложенность через ` / ` в порядке вложенности); запросы без папки сохраняют своё имя. Метод, URL и query-параметры SHALL переноситься: `url.raw` — в URL запроса, элементы `url.query` — в params (отключённые в Postman импортируются со снятой галочкой). Заголовки `header[]` — в headers (отключённые — со снятой галочкой).

#### Scenario: Папки и вложенность
- **WHEN** коллекция содержит папку «Auth» с подпапкой «OAuth» и запросом «Token», и запрос «Ping» вне папок
- **THEN** проект содержит запросы «Auth / OAuth / Token» и «Ping» в порядке обхода дерева

#### Scenario: Query-параметры и disabled
- **WHEN** запрос имеет `url.query` с включёнными `page=2` и отключённым `debug=1`
- **THEN** params запроса содержит оба параметра; у `debug` галочка снята

#### Scenario: Заголовки
- **WHEN** запрос имеет header `Accept: application/json` (включён) и `X-Trace: 1` (disabled)
- **THEN** headers запроса содержит оба; у `X-Trace` галочка снята

### Requirement: Тела запросов по body.mode
Тела SHALL переноситься по `body.mode`: `raw` с `options.raw.lang: 'json'` — тело json, `raw` без него — тело text; `urlencoded` — таблица urlencoded; `formdata` — таблица form-data (текстовые поля; файл-поля с `type: 'file'` импортируются с литеральным значением `@<src>`); режимы `file` и `graphql` — тело none.

#### Scenario: Тело raw с JSON
- **WHEN** запрос имеет `body.mode: 'raw'` с `options.raw.lang: 'json'` и телом `{"a":1}`
- **THEN** тело запроса — json с содержимым `{"a":1}`

#### Scenario: Тело urlencoded и formdata
- **WHEN** запрос имеет `body.mode: 'urlencoded'` с парой `grant_type=client_credentials`, и другой запрос — `formdata` с текстовым полем `note=hi` и файл-полем `doc` со `src: /tmp/doc.pdf`
- **THEN** первый запрос — тело urlencoded с парой; второй — form-data с полем `note=hi` и полем `doc` со значением `@/tmp/doc.pdf`

#### Scenario: Режимы вне поддержки
- **WHEN** запрос имеет `body.mode: 'file'` или `'graphql'`
- **THEN** тело запроса импортируется как none

### Requirement: Авторизация с наследованием от коллекции
Авторизация SHALL переноситься по `auth.type`: bearer — токен, basic — логин/пароль, apikey — ключ, значение и placement (`in: header|query`). Запрос без собственной авторизации SHALL получать авторизацию коллекции, если та задана.

#### Scenario: Авторизация запроса и наследование
- **WHEN** коллекция задаёт `auth.type: 'bearer'` c токеном `t-coll`; запрос A имеет собственный `auth.type: 'basic'` (user/pass), запрос B не задаёт auth
- **THEN** запрос A — basic с логином/паролем, запрос B — bearer с токеном `t-coll`
