# Request Lite

Локальный HTTP-клиент в стиле Postman: Electron + Vue 3 + Vite (electron-vite) + Pinia, чистый JavaScript, тёмная тема. Запросы и окружения хранятся в JSON-файлах на вашем диске — без облака и аккаунтов.

## Возможности

- Запросы с параметрами, заголовками, телами (json / form-data / urlencoded / text) и авторизацией (Bearer / Basic / API Key)
- Отправка строго в main-процессе (нет CORS), Cancel, таймаут 30 с, лимит тела ответа 10 МБ, отключение проверки SSL
- Сохранение запросов в проект, открытие из сайдбара, клонирование
- Окружения и переменные `{{var}}` с подстановкой в момент отправки
- Импорт команд curl и коллекций Postman v2.x, экспорт запросов в cURL
- Блокировка проектов и запросов от случайного удаления/изменения

## Требования

- Node.js ≥ 18

## Запуск в разработке

```bash
npm install
npm run dev          # electron-vite dev, горячая перезагрузка
npm run smoke        # смоук-тесты (чистый Node, без Electron)
```

Для ручных проверок удобно поднять локальный echo-сервер:

```bash
node scripts/echo-server.mjs   # http://localhost:4545
```

## Сборка под конкретную ОС

Сборка выполняется на целевой платформе (для Windows/Linux запускайте на них или используйте CI). Готовые артефакты появляются в папке `release/`.

```bash
npm run dist:mac     # macOS: .dmg / .app
npm run dist:win     # Windows: инсталлятор NSIS
npm run dist:linux   # Linux: AppImage
```

Примечания:

- Подпись кода отключена (`identity: null`, `CSC_IDENTITY_AUTO_DISCOVERY=false`) — приложение собирается неподписанным. Иконка приложения не настроена — используется системная заглушка.
- Конфигурация сборщика — в блоке `build` файла `package.json`.

## Где хранятся данные

Проекты, запросы и окружения лежат в JSON-файлах в папке хранилища (открыть её: меню **Файл → Open data folder**):

| ОС | Путь |
|---|---|
| macOS | `~/Library/Application Support/postman-lite/storage` |
| Windows | `%APPDATA%\postman-lite\storage` |
| Linux | `~/.config/postman-lite/storage` |

Папка закреплена и не зависит от переименований продукта — обновление приложения не трогает ваши данные. Запись атомарная (tmp + rename); повреждённый JSON не затирается — приложение сообщит об ошибке.

## Проекты

- **Создать**: кнопка `+` в заголовке сайдбара или меню **Файл → New Project** (`Cmd/Ctrl+N`).
- **Переименовать**: ✎ в строке проекта (наведите курсор).
- **Заблокировать / разблокировать**: 🔓/🔒 в строке проекта, действие подтверждается в диалоге. У заблокированного проекта у имени отображается 🔒 и кнопка удаления неактивна — удалить его нельзя, пока не разблокируете. Переименование и работа с запросами не ограничиваются.
- **Удалить**: ✕ в строке проекта с подтверждением (удаляются запросы и окружения проекта).
- Активный проект подсвечен; его запросы показаны в разделе «Запросы» ниже.

## Запросы

### Создание и редактирование

- Новая вкладка запроса — `+` на строке вкладок. Заполните метод, URL и вкладки **Params** (query-параметры), **Headers**, **Body** (тип: none / json / form-data / urlencoded / text), **Auth** (No Auth / Bearer / Basic / API Key с выбором «заголовок или query»).
- В таблицах «ключ — значение» включение строки задаётся галочкой: выключенные строки не отправляются. Пустая строка внизу добавляется автоматически.
- **Проверять SSL-сертификат** (вкладка Auth): выключите для серверов с самоподписанными сертификатами.

### Сохранение

- **Save** рядом с Send или меню **Файл → Save Request** (`Cmd/Ctrl+S`). При первом сохранении запрос спрашивает имя (подсказка берётся из URL) и попадает в активный проект; повторное сохранение обновляет тот же запрос без диалога.
- После изменения содержимого на вкладке появляется точка • — признак несохранённых правок.

### Открытие и отправка

- Клик по запросу в сайдбаре открывает его в новой вкладке.
- **Send** — отправка; **Enter** в адресной строке делает то же самое (только когда Send активен); во время отправки кнопка превращается в **Cancel**.
- Ответ: статус/время/размер, заголовки и тело (JSON — с подсветкой). Тело больше 10 МБ обрезается с пометкой.

### Клонирование, блокировка, удаление

- **Клонировать**: правый клик по вкладке → «Клонировать» — создаёт копию содержимого без связи с сохранённым запросом («имя (копия)»); её сохранение создаёт новый запрос.
- **Блокировать запрос**: 🔓/🔒 в строке запроса сайдбара (действие подтверждается). У заблокированного запроса 🔒 у имени, ✕ неактивна, а Save связанной вкладки недоступен («Запрос заблокирован — разблокируйте, чтобы сохранить»). Отправка и клонирование работают как обычно.
- **Удалить**: ✕ в строке запроса сайдбара с подтверждением; открытые вкладки отвязываются, оставаясь открытыми.
- Правый клик по вкладке: **Сохранить**, **Клонировать**, **Копировать как cURL** — действия применяются к кликнутой вкладке.

## Окружения и переменные

- Кнопка ⚙ в тулбаре открывает управление окружениями активного проекта: создание, удаление, редактор имени и таблицы переменных.
- Селектор в тулбаре выбирает активное окружение (или «No Environment»); выбор запоминается для каждого проекта.
- Переменные подставляются в момент отправки во все текстовые поля запроса: `{{baseUrl}}/ping`, заголовки, ключи и значения params/headers, тела. Неразрешённые плейсхолдеры уходят как есть.

## Импорт и экспорт

### cURL

- **Импорт**: меню **Файл → Вставить запрос из cURL** (`Cmd/Ctrl+I`) — вставьте команду, запрос откроется в новой вкладке. Поддерживаются `-X, -H, -d/--data-raw/--data-binary, --json, -F, -u, -b, -G, --url`, слитные формы (`-XPOST`), кавычки и переносы `\`.
- **Экспорт**: правый клик по вкладке → **Копировать как cURL** — справа открывается панель с командой (переменные `{{var}}` переносятся литерально). Кнопка «Копировать» кладёт команду в буфер обмена.

### Коллекции Postman

- Меню **Файл → Импорт коллекции Postman** → выберите JSON-файл коллекции v2.x.
- Коллекция станет новым проектом (имя из `info.name`), папки превратятся в префиксы имён («Folder / Запрос»), тела и авторизация переносятся (raw/json, urlencoded, formdata — без файлов), `collection.variable` станет окружением с именем коллекции — оно сразу активно.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Cmd/Ctrl+N` | Новый проект |
| `Cmd/Ctrl+S` | Сохранить запрос активной вкладки |
| `Cmd/Ctrl+I` | Вставить запрос из cURL |
| `Enter` в адресной строке | Отправить запрос |
| `Enter` в диалогах | Подтвердить |
| `Esc` | Отменить / закрыть диалог или панель |

## Структура проекта (для разработки)

```
src/main/      — main-процесс: окно/меню, HTTP (fetch, Cancel, таймауты),
                 JSON-хранилище (атомарная запись), IPC-каналы
src/preload/   — contextBridge → window.api.* (единственный мост renderer↔main)
src/renderer/  — Vue-приложение: stores (Pinia), компоненты, lib (curl, postman,
                 variables, format — чистые модули)
scripts/       — smoke.mjs (тесты), echo-server.mjs (ручной e2e)
openspec/      — спецификации возможностей и архив изменений
```

Хранилище не зависит от переименований; HTTP выполняется только в main-процессе; renderer изолирован (`nodeIntegration: false`, `contextIsolation: true`).
